# Security Policy

## Supported versions

Security reports are reviewed for the latest released version of Trelune. Please update to the latest release before reporting a vulnerability when possible.

## Reporting a vulnerability

Please report suspected security vulnerabilities privately using [GitHub's private vulnerability reporting](https://github.com/giovannibraaga/trelune/security/advisories/new). Do not disclose vulnerability details in a public issue.

Include a description of the issue, the affected version, steps to reproduce, and the potential impact. Use test accounts and sanitized examples; do not include passwords, access tokens, or other secrets.

The maintainers will review reports as soon as possible and coordinate any fix and public disclosure with the reporter. Please allow time for the issue to be investigated and addressed before sharing details publicly.
